# 🧠 YUSARA Brain Adventure

A colorful **brain-training game for kids**, built in Unity with C# for Android. Simple one-tap mini-games that build focus, reflexes, and shape recognition.

## 🕹️ Mini-Games

- **Target Game** — tap the moving target before the timer runs out, across increasing levels.
- **Shape Game** — pick the right shape (triangle, circle, star, square) as difficulty grows.

## ✨ Highlights

- Kid-friendly design: bright visuals, one-tap controls, encouraging sounds
- Level progression with score and countdown timer
- Smooth animations and level transitions
- Built for Android

## 🛠️ Tech

C# · Unity 6 (2D) · TextMesh Pro · Scene management · `DontDestroyOnLoad` state · Audio manager

## 🚀 Run It

Open **Unity Hub** → **Add** → select this folder → open in **Unity 6** → press **Play**.
